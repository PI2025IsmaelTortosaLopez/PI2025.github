Sistema de Reservas - Proyecto Intermodular
Descripción del Proyecto

Este proyecto consiste en el desarrollo completo de un Sistema de Reservas, realizado como proyecto intermodular.
El objetivo principal ha sido aplicar de forma práctica los conocimientos adquiridos en distintas áreas del desarrollo de software, incluyendo:

Diseño de bases de datos
Modelado entidad/relación
SQL
Desarrollo web con HTML y CSS
Diseño de APIs REST
Programación en Java
Operaciones CRUD

El proyecto integra tanto la parte de análisis y diseño como la implementación funcional de una aplicación capaz de gestionar reservas de forma completa.

Fases del Proyecto
1. Diagrama Entidad/Relación

Diseño inicial de las entidades, atributos y relaciones del sistema.

2. Instalación y Configuración de XAMPP

Preparación del entorno de desarrollo local con Apache y MySQL.

3. Modelo Relacional

Transformación del modelo E/R en tablas relacionales.

4. Modelo Físico en SQL

Implementación completa de la base de datos mediante SQL.

5. Desarrollo Web HTML + CSS

Creación de la interfaz visual de la web consultora.

6. Diseño de API REST

Definición de endpoints y estructura de comunicación.

7. Implementación CRUD

Desarrollo de operaciones:

Create
Read
Update
Delete
8. Aplicación Java

Integración del sistema completo mediante una aplicación funcional.
